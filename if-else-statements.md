# IF ELSE Statements

### `if` statement

```ruby
age = 20

if age > 18
    puts("You can vote")
end

if age < 18
    puts("You cannot vote")
end
```

### `if else` statement

{% code overflow="wrap" %}
```ruby
age = 20

if age > 18
    puts("You can vote")
else
    puts("You cannot vote")
end
```
{% endcode %}



### `if, else if, else` statement

{% code overflow="wrap" %}
```ruby
age = 20

if age > 18
    puts("You can vote")
elsif
    puts("You cannot vote")
else
    puts("A problem occured, please try again")
end
```
{% endcode %}
