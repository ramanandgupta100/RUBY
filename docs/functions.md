# Functions

#### <mark style="color:$success;">functions are written using</mark> <mark style="color:$success;"></mark><mark style="color:$success;">`def`</mark> <mark style="color:$success;"></mark><mark style="color:$success;">&</mark> <mark style="color:$success;"></mark><mark style="color:$success;">`end`</mark> <mark style="color:$success;"></mark><mark style="color:$success;">.</mark>&#x20;

<mark style="color:$success;">There is no need to give () to call it</mark>

<mark style="color:$danger;">Note: Don't give the starting letter of Function Capital (eg: def PrintSomething❌)</mark>



{% code overflow="wrap" %}
```ruby
def printSomething
    puts "Hello"
end

printSomething
```
{% endcode %}



another example

{% code overflow="wrap" %}
```ruby
def calculateSum
    x = 10
    y = 20
    sum = x + y
    puts sum
end

calculateSum
```
